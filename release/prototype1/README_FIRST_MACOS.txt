AVIATION — PROTOTYPE 1 RC1 (macOS)
==================================

Read DOCS/INSTALL_MACOS.txt before installing.

This is a confidential evaluation build — not for redistribution.
Factory audio is synthetic placeholder content, not final commercial material.

Contents:
  Aviation_Prototype1_RC1_macOS.pkg  — installer (installs the VST3 for all users)
  TEST/                              — MIDI test pattern and checklist
  DOCS/                              — Install, known issues, feedback template
  VERSION.txt                        — Build identity (compare with the plugin status bar)
  SHA256SUMS.txt                     — Verify the .pkg before installing

The installer places:
  Aviation.vst3  ->  /Library/Audio/Plug-Ins/VST3/Aviation.vst3

Minimum OS: macOS 10.15
Architectures: universal (Apple Silicon + Intel)

If your host does not show Aviation after installing, rescan plug-ins in the host
and confirm the file exists at the path above.
