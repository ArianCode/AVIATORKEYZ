AVIATION — Prototype 1 — Windows install
========================================

Prerequisites
-------------
- Windows 10 (1607+) or Windows 11. Windows 7/8 are not supported.
- Any x86-64 CPU — Intel and AMD alike. There is no separate build per CPU brand.
- FL Studio with VST3 support — tested matrix: FL 11, 20, 21+, 25.

One bundle covers every FL version
----------------------------------
Aviation.vst3 is a universal bundle. Inside it:

  Contents\x86_64-win\Aviation.vst3   loaded by 64-bit FL (11.1+, 20, 21+, 25)
  Contents\x86-win\Aviation.vst3      loaded by FL 11 32-bit

You install the SAME folder either way — FL picks the half that matches itself.
Check VERSION.txt: the "Architectures" line tells you whether the 32-bit half is
present in the copy you received.

1. Verify the download
   Compare the SHA-256 of the ZIP against SHA256SUMS.txt before extracting.

2. Extract
   Use "Extract All" on the ZIP. Do not run the plugin from inside the ZIP.

3. Install the VST3
   Copy the whole folder  VST3\Aviation.vst3  to the path matching your FL:

     64-bit FL (11.1+, 20, 21+, 25):  C:\Program Files\Common Files\VST3\
     FL 11 32-bit:                    C:\Program Files (x86)\Common Files\VST3\

   Running both a 64-bit FL and 32-bit FL 11 on the same machine? Copy the same
   folder to BOTH paths. Each FL scans only the path matching its own bitness.

   Copy the folder itself, not its contents — Aviation.vst3 is a folder, and FL
   will not recognise it if you unpack it.

4. Rescan in FL Studio
   Options → Manage plugins → Find more plugins → Start scan.
   Confirm "Aviation" appears under Instruments (not Effects).

5. Create a NEW empty project
   Create and save the project in the same FL version you are testing.
   A project saved in a newer FL cannot be opened in an older FL.
   Do not use .flp files from FL 25 macOS on Windows unless the tester also runs FL 25.

6. Load Aviation
   Add Aviation to an instrument channel. Enable MIDI input on the channel.

7. Test MIDI
   Drag TEST\Prototype_Test.mid onto the Piano roll or import it into the project.
   Play — you should hear factory preset audio.

8. Test save and render
   Save the project, close FL completely, reopen it, and play again — the preset
   and its sound must both come back. Then render/export the same project and
   confirm the rendered audio matches what you heard.

Troubleshooting
---------------
- Plugin does not appear after a scan: confirm you copied to the path matching
  your FL's bitness, and that VERSION.txt lists the architecture you need.
- FL 11 32-bit sees nothing: your copy may be 64-bit only. Check the
  "Architectures" line in VERSION.txt.
- Do not use FL's plugin bridging to work around a missing architecture — bridged
  results are not valid for this prototype's acceptance testing.

User presets (optional)
-----------------------

Uninstall
---------
Delete Aviation.vst3 from the VST3 folder(s) above, then rescan plugins in FL Studio.

Support
